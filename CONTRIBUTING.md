# Contributing to Store Insights AI

Welcome, and thank you for your interest in contributing to Store Insights AI! This project is an intelligent chatbot that helps answer questions about store performance using natural language, and we're excited to have your help making it even better. Whether you're fixing a bug, proposing a new feature, or improving documentation, every contribution matters. Please take a moment to read these guidelines before getting started.

## How to Contribute

- **Reporting bugs** — If you find a bug, please [open a GitHub Issue](../../issues/new) with a clear title, a description of the unexpected behavior, steps to reproduce it, and any relevant logs or screenshots.

- **Proposing features** — Have an idea for a new capability or improvement? [Open a GitHub Issue](../../issues/new) labelled `enhancement` and describe the problem you're trying to solve, your proposed solution, and any alternatives you considered.

- **Opening pull requests** — Fork the repository, create a descriptive feature branch (e.g. `feature/my-improvement`), make your changes, and then open a Pull Request against `main`. Link the related issue in the PR description and ensure your changes follow the existing code style.
