# Contributing to Store Insights AI

Thanks for your interest in contributing to Store Insights AI! Whether you're
filing a bug, suggesting a feature, or submitting code, every contribution is
welcome and appreciated.

- **Report bugs** — open a [GitHub issue](../../issues/new) with steps to reproduce, expected behaviour, and actual behaviour.
- **Propose features** — start a [GitHub issue](../../issues/new) describing the use-case and the change you'd like to see.
- **Open pull requests** — fork the repo, create a feature branch, and open a PR against `main`. Keep changes focused and include a clear description of what the PR does.
