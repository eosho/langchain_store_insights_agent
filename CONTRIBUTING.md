# Contributing

Thanks for your interest in improving Store Insights AI. We welcome bug reports, feature ideas, and pull requests from the community. Clear, focused contributions help us review and merge changes faster.

- **Report bugs:** Open a GitHub issue with clear reproduction steps, expected behavior, and actual behavior.
- **Propose features:** Open a GitHub issue describing the problem, the proposed solution, and any relevant use cases.
- **Open pull requests:** Fork the repo, create a focused branch, include a clear description of your change, and link related issues in your PR.
